# Windows runtime license sources

The portable build includes third-party libraries from Python and its Tcl/Tk runtime. Their licenses remain separate from the application MIT license. Python, Pillow, NumPy, tkinterdnd2, and PyInstaller notices are collected directly from the build environment.

- [Tcl-8.6.14.txt](https://raw.githubusercontent.com/tcltk/tcl/core-8-6-14/license.terms)
- [libffi-3.4.4.txt](https://raw.githubusercontent.com/libffi/libffi/v3.4.4/LICENSE)
- [bzip2-1.0.8.txt](https://raw.githubusercontent.com/libarchive/bzip2/bzip2-1.0.8/LICENSE)
- [xz-5.4.6.txt](https://raw.githubusercontent.com/tukaani-project/xz/v5.4.6/COPYING)
- [expat-2.6.3.txt](https://raw.githubusercontent.com/libexpat/libexpat/R_2_6_3/expat/COPYING)
- [zlib-1.2.13.txt](https://raw.githubusercontent.com/madler/zlib/v1.2.13/LICENSE)
- [OpenSSL-3.0.15.txt](https://raw.githubusercontent.com/openssl/openssl/openssl-3.0.15/LICENSE.txt)

Tk 8.6.14 license.terms is copied from the local runtime. The runtime texts here document the current Conda-based build; other Python distributions may bundle different versions.
